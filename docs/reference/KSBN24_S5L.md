# Koetke et al. (2024), Study 5 (long format)

Data from Study 5 in long format for the questions related to trust. The
authors performed repeated measure ANOVA for each of the three response
in term. Also suitable for multivariate analysis of variance. All
responses are measured using a Likert scale ranging from 1 (strongly
disagree) to 7 (strongly agree).

## Usage

``` r
KSBN24_S5L
```

## Format

A data frame with 4074 rows and 5 variables:

- `id`:

  \[factor\] participant identifier

- `statement`:

  \[factor\] statement of the question

- `pih`:

  \[double\] perceived intellectual humility for the statement

- `trustdr`:

  \[double\] score for trust in doctor Wilson

- `trustresearch`:

  \[double\] score for trust in research results of doctor Wilson
