# Work hours

Simulated data for a one-way random effect model on employee attendance.

## Usage

``` r
workhours
```

## Format

A data frame with 320 rows and 3 variables:

- `id`:

  \[factor\] employee identifier

- `week`:

  \[factor\] week of timing

- `time`:

  \[double\] time spent on HEC premises
