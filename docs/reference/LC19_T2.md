# Lee and Choi (2019), Table 2

Contingency table for Study 3, measuring the expected number of products
as a function of the text description and image showing either one or
six toothbrushes.

## Usage

``` r
LC19_T2
```

## Format

A data frame with 12 rows and 4 variables:

- `text`:

  \[factor\] number of toothbrush in text description

- `image`:

  \[factor\] number of toothbrushes displayed in image

- `expected`:

  \[factor\] expected number of toothbrushes

- `count`:

  \[integer\] count of occurence
