# Elliot et al. (2021), dataset 1

Data for Table 2 of Elliot et al. (2021), split by replicating lab. The
data are counts of verbalization, suitable for a generalized linear
mixed model and chi-square test for contingency data.

## Usage

``` r
MULTI21_D1
```

## Format

A data frame with 204 rows and 4 variables:

- `lab`:

  \[factor\] location of laboratory

- `age`:

  \[factor\] age group, one of `5yo`, `6yo`, `7yo` or `10yo`

- `frequency`:

  \[factor\] how often students verbalized during task, one of `never`,
  `sometimes` or `usually`

- `count`:

  \[integer\] count of the number of children
