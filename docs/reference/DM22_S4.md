# Dorison and Minson (2022), Study 4

Exploration of the behavioral consequences of overestimating
self-threat.

## Usage

``` r
DM22_S4
```

## Format

A data frame with 322 rows and 2 variables:

- `wager`:

  amount wagered on ability to persuade counterpart (0-50 continuous
  variable)

- `condition`:

  between-subject experimental condition, either `afraid` or
  `not afraid`
