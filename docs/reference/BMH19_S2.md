# Bobak, Mileva and Hancock (2019), Study 2

Data on matching of pairs of pictures from official ID depending on the
color. Each of the 52 participants was assigned pictures of celebrities
and needed to decide whether pairs of picture (potentially mixed or both
monochrome or color) were of the same person.

## Usage

``` r
BMH19_S2
```

## Format

A data frame with 156 rows and 5 variables:

- `id`:

  \[integer\] participant ID

- `gender`:

  \[factor\] gender of participant, either `male` or `female`

- `age`:

  \[integer\] age of participant

- `color`:

  \[factor\] color of photographs, either grayscale (`mon`), colored
  (`col`) or mixed (`mix`)

- `pcorr`:

  \[double\] percentage of correctly detected match
