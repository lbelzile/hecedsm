# Sharma, Tully, and Cryder (2021), supplementary study 5

Supplementary study 5 of Sharma, Tully, and Cryder (2021). The data
consist of all observations which correctly identified an attention
check. The author tested "whether participants are more interested in
borrowed funds when those funds are labeled as credit rather than a
loan". The preregistration is available at
<https://aspredicted.org/blind.php?x=uv2f5p>

## Usage

``` r
STC21_SS5
```

## Format

A data frame with 1501 rows and 3 variables:

- `purchase`:

  \[factor\] experimental condition for purchase, either `discretionary`
  or non-discretionary (`need`)

- `debttype`:

  \[factor\] experimental condition for label of debt type, either
  `loan` or `credit`

- `likelihood`:

  \[double\] average score of likelihood in/ interest of using offer to
  make the purchase (1-9 scale)
