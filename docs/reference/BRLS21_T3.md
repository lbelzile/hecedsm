# Brodeur et al. (2021), exploratory data analysis

Experiment from Tech3Lab using a driving simulator to study the impact
of various distraction on attention and performance. The experimental
conditions were compared in Table 3 of Brodeur et al. (2021) using
Wilcoxon's signed rank test.

## Usage

``` r
BRLS21_T3
```

## Format

A data frame with 124 rows and 3 variables:

- `id`:

  \[factor\] participant identifier

- `task`:

  \[factor\] type of distraction

- `nviolation`:

  \[integer\] total number of violations
