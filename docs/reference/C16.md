# Chandler (2016) replication

Replication by Chandler (2016) of Study 4a of Janiszewski and Uy (2008).
Both studies measured the amount of adjustment when presented with vague
or precise range of value for objects, with potential encouragement for
adjusting more the value.

## Usage

``` r
C16
```

## Format

A data frame with 120 rows and 4 variables:

- `anchor`:

  \[factor\] anchor, either `round` or `precise`

- `magnitude`:

  \[factor\] magnitude of anchor, 0 or 1

- `gender`:

  \[factor\] participant gender, either `female`, `male` or `other`

- `madjust`:

  \[double\] mean adjustement
